🐆 نصب خودکار Brebde

بدون GitHub — ورکر + KV + کرون همه‌چیز یک‌جا ساخته می‌شود. فقط یک توکن کلادفلر می‌خواهد.

  1. به dash.cloudflare.com/profile/api-tokens برو
  2. Create Token → قالب Edit Cloudflare Workers → Continue → Create
  3. توکن را کپی و اینجا بچسبان

🔒 توکن فقط در مرورگر شما به API کلادفلر ارسال می‌شود و هیچ‌جای دیگری ذخیره نمی‌شود. بعد از نصب می‌توانید همان لحظه توکن را از داشبورد حذف کنید.
